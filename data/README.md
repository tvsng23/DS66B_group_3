# Data

- `raw/e-shop-clothing-2008.csv` is the source clickstream CSV supplied for the project. It is semicolon-delimited (`;`). Keep this source file unchanged.
- Place cleaned/intermediate files generated by notebooks under `processed/`. Files in `processed/` are ignored by Git by default; they should be reproducible by running the necessary notebook(s).

Source: [UCI Machine Learning Repository — Clickstream Data for Online Shopping](https://archive.ics.uci.edu/dataset/553/clickstream%2Bdata%2Bfor%2Bonline%2Bshopping), DOI [10.24432/C5QK7X]. Review UCI's current licence and attribution requirements before redistribution.
